Etiqueta el tipo o estado de un contenido (categoría de noticia, modalidad de trámite).

```jsx
<Badge tone="success" subtle dot>En línea</Badge>
```

- En tarjetas del portal se usa casi siempre `subtle`; el relleno pleno se reserva para fondos claros muy neutros.
- `navy` para comunicados institucionales, `accent` para educación financiera.
